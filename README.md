## Featured projects

### 🔎 [RAG Against the Machine](https://github.com/sweetvain/RAG-against-the-machine)
A Retrieval-Augmented Generation system that answers questions about the vLLM codebase, using BM25 retrieval and a local `Qwen3-0.6B`.

- **84%** recall@5 on docs and **68.7%** on code, over ~28,000 chunks
- Indexing in under a minute on CPU
- Code-aware chunking and a tokenizer that keeps identifiers whole **and** splits snake_case / camelCase
- Robust CLI with no tracebacks, tested with `pytest`

`Python` `bm25s` `Transformers` `PyTorch` `Pydantic`

---

### 🧠 [Call Me Maybe](https://github.com/sweetvain/Call_Me_Maybe)
A fully local **function-calling** engine. It turns natural-language requests into valid, structured function calls using **logit-based constrained decoding**, and detects out-of-scope requests.

`Python` `Qwen3-0.6B` `Pydantic` `uv`

---

### 🧵 [Codexion](https://github.com/sweetvain/Codexion)
A multithreaded take on the Dining Philosophers problem, with per-resource **min-heaps**, **FIFO / EDF** scheduling, a watchdog thread, deadlock prevention and starvation control.

`C` `pthreads` `mutexes` `condition variables`

---

### 🚁 [Fly-In](https://github.com/sweetvain/Fly-In)
A drone logistics simulator: **BFS** pathfinding on a graph with capacity limits, zone types and conflict-free turn-by-turn scheduling.

`Python` `graphs` `mypy` `flake8`

---

### 🌀 [A-Maze-ing](https://github.com/sweetvain/A-Maze-Ing)
A maze generator and solver (iterative **DFS**) with an interactive terminal UI and hexadecimal wall encoding. Built as a team of two.

`Python`
